# Simple Data Filtering

A beginner-level Python project that filters and analyzes student records using a list of dictionaries.

## Objective

To create student records and filter the data based on different conditions such as:

- Marks
- Department
- Age
- Multiple conditions

## Technologies Used

- Python 3
- Jupyter Notebook

## Python Functions and Concepts Used

- List of dictionaries – to store student records
- `for` loop – to process student records
- `if` condition – to apply filtering conditions
- `and` operator – to apply multiple conditions
- Dictionary keys – to access student details

## Filtering Operations

| Filtering Condition | Result |
|---|---|
| Marks 80 or above | Successful |
| MCA Department | Successful |
| Age 21 or above | Successful |
| MCA and Marks 85 or above | Successful |

## Explanation

The student records were stored using a list of dictionaries.

Different filtering conditions were applied to analyze the student data.

Students with marks 80 or above were identified successfully.

Students belonging to the MCA department were filtered successfully.

Students aged 21 or above were also identified.

A multiple-condition filter was used to find MCA students who scored 85 or above.

This task helped demonstrate how Python can be used to filter and analyze structured data using loops, conditions, and logical operators.

## How to Run

1. Open the `Simple_Data_Filtering.ipynb` file in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. View the filtered student records.
